# XR FUSION EDU — versión corregida

## Modelos integrados
La biblioteca incluye los 5 primeros archivos GLB de `models/`. La portada original se conserva.

## Cómo ejecutar en GitHub Pages
1. Sube todos los archivos del proyecto a un repositorio de GitHub.
2. Verifica que `index.html` y la carpeta `models/` estén en la raíz del repositorio.
3. Entra en **Settings** dentro de tu repositorio.
4. Selecciona **Pages** en el menú lateral.
5. En **Build and deployment**, selecciona `Deploy from a branch`.
6. En **Branch**, selecciona `main` y la carpeta `/ (root)`.
7. Pulsa **Save** y espera a que GitHub publique el proyecto.
8. Abre el enlace generado por GitHub Pages para ingresar al laboratorio.
9. Pulsa **ENTRAR AL LABORATORIO**. Los 5 primeros modelos aparecen en **BIBLIOTECA 3D** a la izquierda.

No muevas `index.html` fuera de la carpeta ni separes `models/`: las rutas de los modelos son relativas (`./models/nombre.glb`).
